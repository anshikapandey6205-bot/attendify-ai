# Attendify AI

Attendify AI is a student attendance management system using
face recognition.

## Features

- Student registration
- Face recognition attendance
- Attendance reports
- Student dashboard
- Database management

## Technologies

- Python
- Flask
- HTML/CSS
- JavaScript
- SQLite
- Face Recognition
